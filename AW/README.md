# Synergy AW GSC Menu

An Exo-Zombies GSC Mod Menu that uses [S1x/Alterware](https://alterware.dev/)

### Requirements: [S1x/Alterware](https://alterware.dev/)

## Installation:

* Download [Synergy.gsc](https://syndishanx.github.io/Synergy-GSC-Menu/AW/Synergy.gsc)

* Place it into `data\scripts` in the Game Folder

* Download [s1-mod.exe](https://syndishanx.github.io/Synergy-GSC-Menu/AW/s1-mod.exe)

* Place it into your Game Folder, replacing the default Client, this is a fixed version by lusif3ar
