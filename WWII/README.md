# Synergy WWII GSC Menu

A World War II Zombies GSC Mod Menu that uses [S2x](https://github.com/Brentdevent/S2x)

#### Preview:

![Mod Menu](https://syndishanx.github.io/Synergy-GSC-Menu/WWII/Synergy-GSC-Menu.png)

### Requirements: [S2x](https://github.com/Brentdevent/S2x)

#### Zombies:

* Download [Synergy.gsc](https://syndishanx.github.io/Synergy-GSC-Menu/WWII/Synergy.gsc)

* Place it into `s2x/scripts`

##### Known Issues:

* Zombie Counter will be Incorrect for the Round you Enable it on

* Opening All Doors before Turning on the Power Manually will Cause some Doors to be Visually Closed, but you can still go through them (The Salt Mine Door on The Final Reich)

* Menu will disconnect you if you scroll through too many Menus in a Single Game
