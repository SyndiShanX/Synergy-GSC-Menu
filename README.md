# Synergy GSC Menu

A GSC Mod Menu for Various Games

These Menus are a Work-In-Progress, so expect changes and possibly some Bugs

If you use any Code from my Menus, your Menu also has to be Open-Source as per the [GNU GPLv3 License](https://github.com/SyndiShanX/Synergy-GSC-Menu/blob/main/LICENSE.md)

If you have any Issues/Suggestions, please Submit them in [Issues](https://github.com/SyndiShanX/Synergy-GSC-Menu/issues)
