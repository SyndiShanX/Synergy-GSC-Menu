# Synergy MWIII GSC Menu

A Modern Warfare III Zombies GSC Mod Menu that uses the [Lumen MWIII Client](https://discord.gg/projectlumen)

#### Preview:

![Mod Menu](https://syndishanx.github.io/Synergy-GSC-Menu/MWIII/Synergy-GSC-Menu.png)

### Requirements: [Lumen MWIII Client](https://discord.gg/projectlumen)

## Installation:

#### Zombies:

* Download [Synergy.gscc](https://syndishanx.github.io/Synergy-GSC-Menu/MWIII/Synergy.gscc)

* Place it into `jupiter\Assets\Scripts\Custom\zm`

##### Known Issues:

* Perks can be Applied Multiple Times
* Controls Pop up too early so they are hidden by the Infil Cutscene
* You can't open/interact with the Menu if your Aiming Input Device is set to Controller
