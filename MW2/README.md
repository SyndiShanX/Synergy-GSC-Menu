# Synergy MW2 GSC Menu

A Modern Warfare 2 GSC Mod Menu using [IW4x](https://github.com/iw4x)

### Requirements: [IW4x](https://github.com/iw4x)

## Installation:

* Download [Synergy.zip](https://syndishanx.github.io/Synergy-GSC-Menu/MW2/Synergy.zip)

* Extract the ZIP and Place the `Synergy` Folder into the `mods` folder in the game files
