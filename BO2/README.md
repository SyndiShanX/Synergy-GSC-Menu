# Synergy BO2 GSC Menu

A Black Ops 2 Zombies GSC Mod Menu using [Plutonium](https://plutonium.pw/)

### Requirements: [Plutonium](https://plutonium.pw/)

## Installation:

#### Zombies:

* Download [Synergy.gsc](https://syndishanx.github.io/Synergy-GSC-Menu/BO2/Synergy.gsc)

* Place it into `%localappdata%\Plutonium\storage\t6\scripts\zm`

#### Multiplayer:

* Download [Synergy_MP.gsc](https://syndishanx.github.io/Synergy-GSC-Menu/BO2/Synergy_MP.gsc)

* Place it into `%localappdata%\Plutonium\storage\t6\scripts\mp`
